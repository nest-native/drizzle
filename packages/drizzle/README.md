# @nest-native/drizzle

> **Deprecated.** Use NestJS's official Drizzle module,
> [`@nestjs/drizzle`](https://docs.nestjs.com/data/drizzle), instead. 0.5.2 is
> the last release of this package. The
> [migration guide](https://nest-native.github.io/drizzle/docs/migrate-to-nestjs-drizzle) maps every API to
> its replacement.

Nest-native Drizzle ORM integration with `DrizzleModule`, `@InjectDrizzle()`,
`@DrizzleRepository()`, transaction decorator bridges, and testing helpers.

See the repository
[README](https://github.com/nest-native/drizzle#readme) and
[documentation](https://nest-native.github.io/drizzle/)
for quick-start examples, transactions, testing, quality gates, and support
policy.
